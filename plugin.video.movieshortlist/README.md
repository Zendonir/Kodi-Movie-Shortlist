# Movie Shortlist (plugin.video.movieshortlist)

Kodi add-on for collecting movie-night candidates from the Kodi movie library.
Full documentation (German): see README.md in the project repository.

- Context menu of a library movie: "Zur Filmauswahl hinzufügen" / "Aus Filmauswahl entfernen"
- Add-ons > Video add-ons > Movie Shortlist: list, random pick, sort order, clear list
